## Featured project

### [SightScreen](SIGHTSCREEN_REPO_LINK): live cricket win probability · [Live demo](SIGHTSCREEN_LIVE_LINK)

A full-stack platform that predicts which team will win, updated after every delivery of a live match.

- Trained a LightGBM model on **3.8M+ deliveries from 13,000+ matches**
- Serves predictions at **702ms median / 918ms p95 latency** through a FastAPI backend and a Next.js frontend
- Deployed across Vercel, Railway, and Supabase
- Ships a public accuracy dashboard that separates live from replayed predictions and publishes where the model is miscalibrated, because a prediction you can't check isn't worth much

**Stack:** Python, LightGBM, FastAPI, Next.js, TypeScript, Supabase
